## 快速上手

1. 电脑上双击运行神灯监控，左上角显示**本机设备码**（如 `A1B2C3D4E5F6`），点「复制」
2. 手机浏览器打开 `pinodewatch.top`，粘贴设备码，点「添加」
3. 设备出现在列表中，全部功能即可在手机上操作

## 神灯远程桌面

通过自建服务器中转，电脑端需先部署客户端并注册为系统服务，之后可由手机直接进入桌面，免密码、免装 APP。

**① 部署**：打开神灯监控 →「📊 本机监控」页滚到最底部 →「🟢 神灯远程桌面」→ 点「📦 一键部署」，等弹出「部署成功」

**② 确认**：点「🔃 刷新状态」**两次**，显示「✅ 已连接」+ 设备 ID 才算真的上线

**③ 开通**：远程桌面为增值服务，点「💎 去开通远程桌面」自助购买，或联系客服（微信 `pijd2019`）报设备 ID
